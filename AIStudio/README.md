# AI Studio

AI Studio — локальный Windows-контроллер ComfyUI с русским адаптивным PWA-интерфейсом. Генерация выполняется в подключённом ComfyUI; браузер на ПК или телефоне управляет заданиями через защищённый backend и не получает прямой доступ к движку.

## Что реализовано

- внешний и управляемый режимы ComfyUI;
- запуск и остановка только процесса, созданного AI Studio;
- импорт UI JSON и API JSON, анализ по `/object_info`, динамические поля и явные сообщения о недостающих нодах/моделях;
- контроль ревизии workflow и отправка снимка актуального API-графа в `/prompt`;
- редактор графа с перемещением, zoom, соединениями с проверкой типов, удалением, дублированием, bypass/mute и undo/redo;
- очередь, отмена через `/interrupt` и `/queue`, WebSocket-прогресс, история и прокси результатов `/view`;
- загрузка референсов, PWA, мобильная переподключаемость без повторной отправки задания;
- Ollama, LM Studio, OpenAI Responses API и произвольный OpenAI-compatible endpoint;
- Prompt Enhancer с обязательным просмотром результата или явно включаемым автопродолжением;
- подтверждаемые предложения ассистента для графа с проверкой существующих нод/входов и резервной копией предыдущей ревизии;
- пакет нод `ai_studio_nodes` для LLM, vision и структурированной сцены;
- модельные корни через `extra_model_paths.yaml`, просмотр разрешённых серверных папок;
- профили `--lowvram`, стандартный и `--highvram`, реальные метрики `/system_stats`, выгрузка моделей `/free`;
- токен доступа к backend; ключ провайдера шифруется ASP.NET Data Protection с DPAPI на Windows;
- self-contained x64-публикация и Inno Setup с ярлыками и отдельным выбором удаления пользовательских данных.

## Запуск для разработки

Требуется .NET 8 SDK.

```powershell
dotnet run --project AIStudio/AIStudio.csproj
```

При первом запуске откроется `http://127.0.0.1:7123` с одноразово переданным токеном. Настройки, workflow, результаты и журналы хранятся в `%LOCALAPPDATA%\AI Studio`.

### ComfyUI

Для внешнего режима укажите адрес уже запущенного ComfyUI, обычно `http://127.0.0.1:8188`.

Для управляемого режима используйте отдельную распакованную установку ComfyUI/ComfyUI Portable и укажите:

- папку с `main.py`;
- `python.exe` (для Portable обычно `python_embeded\python.exe` находится автоматически);
- свободный порт.

AI Studio создаёт собственные папки результатов, референсов, моделей и настроек, а также собственный `extra_model_paths.yaml`. Пакет AI Studio nodes копируется только в управляемую установку и только если папка пакета ещё отсутствует. Внешняя установка не изменяется.

## Сборка Windows

```powershell
./AIStudio/build-windows.ps1
```

Результаты:

- `AIStudio/publish/AIStudio.exe` и необходимые файлы приложения;
- `AIStudio/artifacts/AIStudio-Setup-x64.exe`.

Для сборки без установленного Inno Setup используйте `-SkipInstaller`. Workflow GitHub Actions `Build AI Studio for Windows` собирает и публикует оба артефакта автоматически.

## Телефон и безопасность

Включите LAN-доступ в настройках и перезапустите AI Studio. Откройте адрес ПК с портом AI Studio и введите токен. Для удалённого доступа настройте Tailscale или другой защищённый канал с HTTPS. Не публикуйте ComfyUI и порт 8188 в интернет. Service Worker PWA активируется только на localhost или HTTPS, как требуют мобильные браузеры.

## Проверенные и непроверенные сценарии

В Linux CI проверяются компиляция, запуск backend, авторизация, выдача PWA, сохранение настроек и импорт API workflow. Windows GUI, Inno Setup, ComfyUI с NVIDIA GPU, реальные модели, провайдеры с ключами и мобильный HTTPS требуют проверки на целевой машине. Программа не выдаёт эти сценарии за успешно выполненные без соответствующей среды.

Текущие ограничения: автоматическая загрузка ComfyUI/Python/PyTorch не выполняется — это намеренно исключает неявную многогигабайтную установку и выбор несовместимой CUDA-сборки. Управляемому режиму требуется отдельная установленная копия ComfyUI. Преобразование сложных frontend subgraph сохраняет исходный UI JSON, но для разворачивания subgraph может потребоваться совместимая версия официального ComfyUI frontend.
