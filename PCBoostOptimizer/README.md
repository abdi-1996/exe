# PC Boost — оптимизация Windows

Нативное приложение для Windows 10/11, созданное для безопасной базовой оптимизации ПК. Интерфейс на русском языке.

## Что умеет

- Показывает свободную оперативную память, место на системном диске, временные файлы и количество программ в автозагрузке.
- Работает в фоне: обновляет загрузку ЦП, ОЗУ и системного диска каждые 2 секунды.
- Показывает компактную мини-панель поверх всех программ; её можно перетащить в нужное место, скрыть или вернуть через значок в системном трее.
- Может запускаться автоматически вместе с Windows в свёрнутом режиме.
- Выполняет безопасное фоновое обслуживание: раз в 30 минут удаляет только незанятые файлы старше 7 дней из пользовательской папки `%TEMP%`.
- Очищает только выбранные категории: пользовательские временные файлы, отчёты о сбоях, Windows Internet Cache, системный Temp и корзину.
- Не удаляет документы, фотографии, программы, драйверы, обновления Windows или точки восстановления.
- Управляет автозагрузкой текущего пользователя и сохраняет обратимую резервную копию каждого отключённого пункта.
- Показывает процессы с наибольшим потреблением памяти и не позволяет завершить критические системные процессы.
- Даёт быстрый доступ к штатным инструментам Windows: очистка диска, оптимизация накопителей, настройки питания, обновления Windows.
- Может очистить DNS-кэш, создать точку восстановления и запустить `SFC /scannow` после явного подтверждения.

## Запуск

### Готовая сборка через GitHub Actions

1. Загрузите содержимое этой папки в новый GitHub-репозиторий.
2. Откройте вкладку **Actions** → **Build PC Boost for Windows** → **Run workflow**.
3. После завершения скачайте артефакт `PCBoostOptimizer-win-x64` — внутри будет `PCBoostOptimizer.exe`.

### Сборка на Windows

1. Установите [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Дважды нажмите `build-exe.bat`.
3. Готовый файл появится в папке `publish` как `PCBoostOptimizer.exe`.

Также можно выполнить команду вручную:

```bat
dotnet publish PCBoostOptimizer.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish
```

## Права администратора

Основные функции работают без администратора. Права администратора нужны только для:

- очистки `C:\Windows\Temp`;
- создания точки восстановления;
- запуска проверки системных файлов SFC.

Нажмите кнопку **«Запустить как администратор»** в правом верхнем углу приложения, если нужна одна из этих функций.

## Важно

PC Boost намеренно не делает «одним кликом всё»: оптимизаторы, которые автоматически отключают службы, очищают реестр или меняют параметры Windows, могут сломать систему. Любые значимые изменения выбираются и подтверждаются пользователем; в фоне выполняется только отключаемая очистка старых файлов из пользовательского `%TEMP%`.

## Фоновый режим и мини-панель

Во вкладке **«Фоновый режим»** можно:

- включить или приостановить мониторинг в реальном времени;
- включить/выключить безопасное автообслуживание временных файлов;
- показать или скрыть мини-панель поверх всех программ;
- включить запуск PC Boost вместе с Windows.

Закрытие основного окна не завершает программу: она сворачивается в системный трей и продолжает обновлять мини-панель. Для полного завершения нажмите правой кнопкой на значок PC Boost в трее и выберите **«Выйти из PC Boost»**.
